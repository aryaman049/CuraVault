# Security Specifications

- **Auth**: Supabase Auth handles identity. Access tokens stored in `httpOnly` cookies.
- **Authorization**: Express middleware checks MongoDB ownership on every request (IDOR prevention).
- **Storage**: Supabase Storage is private. Accessed via short-lived (5 min) signed URLs generated by the backend.
- **Sharing**: Temporary tokens are generated for doctors. Tokens are hashed (SHA-256) before storing in the database.
- **AI Safety**: LLM is instructed not to diagnose. Output is strictly validated with Zod.
- **Logging**: All accesses to shared sessions are logged to `access_logs`.
