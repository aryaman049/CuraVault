# CuraVault Prototype

A web application prototype for secure medical document management, featuring AI-powered OCR extraction and secure sharing.

## Setup
- **Backend**: Express + MongoDB Atlas + Supabase (Auth/Storage)
- **Frontend**: Next.js (App Router)

### Environment Variables
Copy `.env.example` to `.env` in both frontend and backend and populate with your credentials.

### Run Locally
Backend: `cd backend && npm install && npm run dev`
Frontend: `cd frontend && npm install && npm run dev`
